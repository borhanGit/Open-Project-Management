# Security Policy

## Supported Versions

We actively provide security patches for the latest release:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **OpenProject Laravel**, please **DO NOT** open a public issue.

Instead, please send an email with details, reproduction steps, and potential impact directly to the maintainers or use GitHub's private vulnerability reporting feature under the **Security** tab of this repository.

### What to include in your report:
- A clear description of the vulnerability
- Steps to reproduce or a minimal proof of concept (PoC)
- Potential impact and affected endpoints
- Suggested patch or mitigation (if available)

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure and patch release.
